## 3. Извършени дейности

Подготвени са следните файлове:

- docs/RESEARCH.md — проучване на Koha, Libib и Open Library.
- docs/PROJECT_PLAN.md — план на функционалностите.
- docs/PRODUCT_SPEC.md — описание на двата екрана.
- ER_DIAGRAM.md — начална диаграма на базата данни.
- catalog-mockup.svg — макет на каталога.
- librarian-mockup.svg — макет на библиотекарския панел.
- index.html — HTML структура.
- style.css — CSS оформление.
- script.js — примерни книги и търсене.

Създадено е GitHub хранилище с 12 Issues.

Публикувана е начална версия чрез GitHub Pages:
https://boris2010-d.github.io/BookConnect/

## 4. Какво работи към момента?

Началната версия съдържа:

- Каталог с пет примерни книги.
- Търсене по заглавие и автор.
- Показване на примерна наличност.
- Адаптивно оформление.

Книгите все още не се зареждат от база данни.
Регистрацията, заемането и резервациите не са реализирани.

## 5. Неизпълнени задачи

- Създаване на реална Supabase база данни.
- Регистрация и вход на потребители.
- Реално заемане и връщане на книги.
- Резервации и известия.
- Автоматизирани тестове.

Причина: тези функционалности са планирани
за следващите седмици.

## 6. Срещнати затруднения

При създаването на index.html първоначално
файлът беше запазен без HTML съдържание.
Проблемът беше решен чрез редактиране
на файла в GitHub.

При публикуването на сайта чрез GitHub Pages
беше необходимо да се изчака завършването
на процеса по публикуване.

## 7. Задачи за следващата седмица

1. Създаване на Supabase проект и таблици.
2. Свързване на каталога с базата данни.
3. Добавяне на регистрация и вход.
4. Подобряване на мобилния интерфейс.
5. Проверка на търсенето с различни данни.

## 8. Използване на изкуствен интелект

Използван инструмент: ChatGPT.

Цел: помощ при проучване, планиране,
структуриране на документацията и
разработване на начален HTML, CSS и
JavaScript прототип.

Примерна заявка:
"Помогни ми да разработя начална версия
на училищна библиотека BookConnect
с HTML, CSS и JavaScript."

Получен резултат:
Примерна структура на сайта, CSS оформление,
JavaScript за каталог и търсене и
предложения за документация.

Проверка:
Файловете са качени в GitHub.
Публикуването е проверено чрез GitHub Actions.
Сайтът се отваря чрез GitHub Pages.

Допълнително трябва да се провери
търсенето по заглавие и автор.
